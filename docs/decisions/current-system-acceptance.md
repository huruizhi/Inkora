# 本轮验收使用当前 macOS

2026-11-10，用户明确指示：“不验收14版本。继续推进”。本决定取代本轮首阶段和候选交付清单中要求另行取得 macOS 14 实机/VM 结果的条款。

- 本轮在当前可用 macOS 环境执行功能、文件、输入法、辅助功能和显示验收，并记录真实系统版本与架构；不再以缺少 macOS 14 环境阻塞。
- 产品平台和 deployment target 仍为 macOS 14+。本决定不修改构建、availability 守卫、依赖或有效测试，不把在新系统编译运行写成 macOS 14 实测通过。
- macOS 14 兼容性状态明确为“未执行版本专门验收”，而不是通过；对外支持声明须区分部署目标与实际测试系统。
- 其余数据完整性、composition、选区/撤销、真实 Sandbox、保存/重开、键盘/AX、当前系统深浅色/放大字体及性能门槛保持。默认 CI 仍不自动加入 UI；需要桌面的实际验证沿用互斥、预检和专用测试 bundle。

本决定来自用户直接调整验收范围，不来自绿色测试数量或实现困难；不修改原始失败证据、golden、历史运行结果或首阶段功能范围。
