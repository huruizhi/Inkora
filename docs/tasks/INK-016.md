# INK-016：文档保存与原子写入

- 来源：GitHub Issue #16
- 分支：`task/INK-016-document-save`
- 依赖：INK-015 文件打开、Bridge revision 与 Save Barrier

## 交付范围

- File > Save / Save As 标准入口与快捷键；
- revisioned snapshot 保存屏障与连续保存 FIFO；
- `NSDocument` safe save 加原子 writer；
- Save As 路径切换、系统覆盖确认和取消语义；
- 成功后的 `markSaved` baseline 确认；
- 权限、磁盘和 snapshot 失败时保留旧文件及 dirty 状态；
- Swift、TypeScript 和 macOS UI 自动化覆盖。

## 非范围

- 自动保存；
- 崩溃恢复草稿；
- 外部文件变更协调。
