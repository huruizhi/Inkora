# INK-013：Revision 同步、Snapshot 与 Save Barrier

- 来源：GitHub Issue #13
- 分支：`task/INK-013-revision-save-barrier`
- 依赖：Bridge v1、WKWebView 离线宿主、Markdown serializer

## 交付范围

- 将 ProseMirror history/dirty runtime 接入生产编辑器；
- 未知 Markdown 的保真源码模式与 revisioned Undo/Redo；
- 用户编辑、IME、Undo/Redo 的单调 revision 状态；
- 原子 `createSnapshot` 最低 revision 门槛；
- 并发请求、有限重试、超时、迟到响应与乱序隔离；
- 快速输入立即保存、并发 snapshot、保存后继续编辑、Undo 后 snapshot 和超时测试。

## 非范围

- 磁盘原子写入与保存面板；
- 原生菜单命令绑定；
- Web Content process 自动恢复。
