# INK-014：Bridge 错误恢复与诊断

- 来源：GitHub Issue #14
- 分支：`task/INK-014-bridge-recovery-diagnostics`
- 依赖：Bridge v1、revision/save barrier、WKWebView 离线宿主

## 交付范围

- `retry`、`notify`、`stop_saving` 到重试、用户提示和停止保存的固定映射；
- 初始化失败、非法消息、snapshot 超时和恢复失败的保存阻断；
- Web Content process 终止检测与一次自动重新加载；
- 只重放最近确认 snapshot，不把未确认 Web 状态写回文件；
- 包含 request ID、revision 和错误类别的结构化统一日志；
- 超时、非法消息、进程终止、恢复失败和错误动作映射的故障注入测试。

## 非范围

- 未确认编辑的持久化崩溃恢复草稿；
- 应用重启后的会话恢复；
- AI 或网络诊断上报。
