# INK-M1-046：离线代码高亮与语言选择

状态：实现候选，等待管理者真实 WKWebView / 物理输入法后验。

## 完成范围

- 只打包 `highlight.js@11.12.0` core 与约定的常用语言，不自动检测、不访问网络。
- 使用安全解析后的 token 区间生成 ProseMirror inline Decoration；HTML 不进入编辑 DOM。
- 按 code node 缓存高亮结果，未变化的代码块不会重复运行 highlighter。
- 围栏代码块提供中文、键盘可达的语言选择器；未知语言与 alias 原样可见。
- 语言变更走 `view.dispatch(setNodeMarkup)` 和既有 `fence-language` 原文补丁链。
- 缩进代码块明确禁用语言持久化；composition 期间零事务且不夺编辑器焦点。
- BSD-3-Clause notice 随 Vite 产物和应用资源分发。

## 保真边界

高亮是纯视图派生，不参与原文、选区、历史、dirty 或 revision。语言变更只替换 info
string 首 token，并保留其余 info、BOM、LF/CRLF、围栏和代码正文。未知语言不触发
自动检测，也不会被改写。

## 验收说明

自动化覆盖语言/alias/未知语言、多 info、恶意标记字面显示、emoji、BOM/CRLF、缓存、
真实 runtime DOM、代码编辑后的高亮刷新、语言 patch、no-op、Undo/Redo、源码往返、
重开和 composition 守卫。jsdom 验收是 synthetic，不替代管理者的真实 WKWebView 和
物理中文输入法检查。
