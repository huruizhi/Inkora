# INK-M1-013 源码模式原子替换

## 完成内容

- 显式拆分源码定位与替换能力：仅可编辑 `SourceEditorRuntime` 开放替换；PM 与 bare-CR 均不开放，也不自动切换模式。
- 增加单行字面 replacement 输入、替换当前正文精确选中匹配、全部替换；截断结果禁用全部替换。
- 在 plan/runtime/main/DOM 四个真实接缝建立回归。main 执行点重验 documentID、revision、raw、load epoch、query、case、结果和 replacement 意图。
- runtime 原子提交前验证 textarea 投影、计划 source、降序不重叠补丁、范围/expected、Unicode/CRLF/字素边界、resultRaw 重推导和结果选区。失败与 no-op 零写入；真实变更一次历史、一次通知、一次 revision。
- 替换链 Undo/Redo 保存替换前后 raw 与有向选区；查询、replacement 和 runtime composition 统一阻止替换/导航/关闭等交互，跨 load 延迟清候选并忽略晚到 final input。

## 限定补正

- 将源码历史改为私有的不可变 before/after entry。替换提交时同时冻结两端 raw 与有向选区；之后移动 caret 不再污染 Undo 生成的 Redo 快照，连续替换可逐单元往返。
- 把 plan 当作不可信输入：拒绝尾部孤立高代理项、引入裸 CR 的结果，以及 `changed=true` 但 `resultRaw` 与当前 raw 字节相同的伪变更。拒绝发生在 raw、history、future、选区与通知变更之前。
- replacement 输入处于 composition 时，即使新文档暂时 idle 或最终切到 bare-CR/PM，也保留同一个候选 DOM 与焦点；`compositionend` 后执行新文档重置、移除不再可用的控件，并忽略晚到 final input。
- 产品回归覆盖尾部高代理项的 expected/insert/result、bare CR、伪 no-op/future、连续两次替换及移动 caret 后多次 Undo/Redo，以及 source 跨 load 到 bare-CR/PM 的候选 DOM 生命周期。
