# INK-010：检测未知 Markdown 并阻止静默数据丢失

- 来源：GitHub Issue #10
- 分支：`task/INK-010-markdown-safety`
- 依赖：INK-002 / #2、INK-009 / #9

## 交付范围

- 未知/延后语法的保守检测与固定风险码；
- 行列/字符范围和不含正文的用户风险状态；
- 代码、链接范围保护，避免字面量误报；
- 未修改、结构化与完整源码缓冲区三类保存策略；
- GFM 表格、任务列表、脚注、HTML、自定义容器负向 fixtures；
- 图片、裸链接、MDX/JSX、模板和延后语法补充测试。

## 非范围

- 在 ProseMirror 中渲染不透明原始片段；
- NSDocument 原子写盘和原生提示；
- 立即支持所有检测到的 Markdown 方言。
