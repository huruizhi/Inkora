## 未完成事项与风险

VoiceOver、真实中文输入法、最低系统、Finder/只读卷等人工清单待执行。
系统菜单键盘焦点、系统面板结构和 AX 审计可能随 OS 变化；失败应分析 xcresult，不能静默豁免。
失败快照为最近成功取得的 Bridge snapshot；composition / 进程失败可能无法获得更新，附件如实标明。
固定截图仅作结构/人工审阅证据，不保证跨系统像素一致。测试专用诊断 hook 增加 UI 测试中的 snapshot 请求，不影响正式 bundle。
