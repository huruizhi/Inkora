## 本任务补正

- collapsed caret 位于现有链接 label 时，`Mod-K` 以 source-ledger 的单一 owner 作为编辑目标；owner 同时绑定 block source range 与自身源码坐标，更新和移除不依赖 `ownerSerial` 全局唯一性，也不按 href 或正文字符串合并相邻/跨块链接。
- owner 链接编辑在 source-authority 内原子校验候选原文、投影、owner 属性与有向选区；任一步失败均回滚原文、选区与历史。取消和 no-op 不清空 future。
- 局部 mark、后向选区、行内链接空白及 destination/title 定界风格尽量保留；唯一引用继续修改原定义，共享引用只把当前 owner 转为行内链接，避免污染其他引用。
- 链接 href/title 输入框拥有独立 composition 生命周期。提交、移除、取消、Escape、模式切换、查找打开、大纲导航与跨 load 的破坏性路径统一守卫；跨 load 保留候选 DOM 到 compositionend，旧提交拒绝且不污染新文档。
- 链接表单持焦或 composition 时，Native 文档 Undo/Redo 通过既有 `command_rejected` 路径拒绝；焦点回正文后仍使用正常文档历史。
- 文档 `handleKeyDown` 对 `event.isComposing` 的 Cmd-Z/Cmd-Shift-Z/Ctrl 变体不消费，普通 Undo/Redo 保持可用。
