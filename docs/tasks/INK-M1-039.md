## 本切片实现

- 以唯一当前 Markdown 原文作为内容权威；ProseMirror 文档、语义分析、位置映射和保存状态均从同一会话派生。
- 可视事务以局部原文补丁提交，保留 BOM、LF/CRLF/mixed EOL、尾部换行、Unicode 与未触及格式字节；保存点只接纳原生确认的精确 snapshot 文本。
- 主动源码入口提供草稿、提交和取消；未提交草稿、未解决意图和畸形输入阻断 snapshot，不返回旧文本充数。源码提交与可视编辑共享 Undo/Redo 历史。
- Bridge 逻辑 revision 与内部原文版本分离；IME 组合中间态不发布多个 Bridge revision，结束后按一个逻辑单元发布。
- 可见且键盘可达的可视/source 切换及 apply/cancel 已接入真实 `main` DOM；大纲、统计、标题定位、查找焦点隔离和源码导航/原子替换沿用现有生产路径。
- 稳定高级片段保留精确原文并与可视正文混排；畸形候选保留当前原文和可信投影并开放源码修复。bare CR 继续只读。
