# INK-M1-050：生产表格与任务列表直接编辑

状态：非UI完成候选；真实 WK、物理中文输入、VoiceOver 与正式 NSDocument 保存/关闭/重开由调度者独立验收。

## 实现

- 扩展生产 schema 与 Markdown parser：真实 table/section/row/header/cell 节点，以及带任务状态的 list-item；合法表格不再进入 INK-055 原子预览，列数不匹配仍是普通 Markdown。
- 扩展原文账本和事务：cell/label 精确范围、转义管道、缺格锚点、隐藏额外格、引用/列表容器、CRLF/Unicode；表格文字要求唯一精确重解析候选，结构与 checkbox 命令带当前 PM 基线并原子提交。
- 新增生产 NodeView：表格工具栏、Tab/Shift-Tab、末格增行、真实任务 checkbox、Space 与准确 AX 名称；composition 期间拒绝结构动作且不夺候选键。
- 接入 runtime/main/Bridge：可在当前顶层块后新建两列表，空白文档直接替换空段落；snapshot、markSaved、源码往返、Undo/Redo 与新会话重开继续使用既有正式流程。
- 文档分析不把任务 marker 和表格管道计入内容统计；样式覆盖可编辑表格、工具栏、任务 label 与焦点。
