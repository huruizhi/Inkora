# INK-M1-068：表头邻接插行与 BOM 表格归属

基线 `b30b368e5b5598e2d912512049b08b8a277cba5a`，独立分支 `task/INK-M1-068-table-header-insertion`。管理者在 PR72 非 UI 候选复核中发现“选中表头→后插行”被拒，未占用桌面。

## 原因与修复

- 首个真实 toolbar/EditorView 红例：两数据行表格选中表头，点击“后插行”，实际 tbody 仍只有原两行，命令被重解析等价检查拒绝。
- 排序假设为 PM 数据行索引偏移、原文插入偏移、选中行归属错误。只改 PM 索引后 LF 红例转绿：表头不在 `bodyRows`，其邻接数据行应插在索引 0，不能再加 after 偏移。原文补丁规则无需改变。
- 扩展 BOM+CRLF、无数据行/无尾换行后，全量出现 482 pass / 1 fail。BOM 失败诊断为“顶层 table 缺少 source token 或 PM 节点”：物理 token 行从 0 开始，而模型范围从 BOM 后的 1 开始。改用已有正文/嵌套范围相同的 token 所有权重叠判据；不忽略解析错误或放宽 `doc.eq`。
- 三组真实工具栏回归核验独立字节预期、数据行顺序、保存快照、dirty 和单步 Undo/Redo；保留所有既有测试和冻结 oracle。
