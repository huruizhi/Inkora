# INK-009：实现 Markdown parser、serializer 与 golden fixtures

- 来源：GitHub Issue #9
- 分支：`task/INK-009-markdown-codec`
- 依赖：INK-002 / #2、INK-008 / #8、INK-007 / #7、INK-006 / #6

## 交付范围

- 当前 schema 支持节点/marks 的 CommonMark parser 与 serializer；
- strike 扩展、soft/hard break 区分和 Unicode 原样传递；
- 标题、列表与 code block 来源风格属性；
- 稳定规范化、围栏冲突增长和未闭合 fence；
- 行内、嵌套、代码与未闭合四组 golden fixture；
- 结构固定点、输出固定点、代码/链接边界测试。

## 依赖说明

- `prosemirror-markdown` 提供官方 ProseMirror codec 框架；
- `markdown-it@14` 与该版本 `prosemirror-markdown` 的公开类型及运行时范围一致；
- `@types/markdown-it` 为 parser 插件规则提供严格 TypeScript 类型。

## 非范围

- 图片、表格、任务列表和未知扩展语法；
- 原始字节范围映射与未知语法保存闸门（Issue #10）；
- 将当前 textarea 替换为 ProseMirror view。
