# INK-055：编辑器滚动与扩展 Markdown 预览

## 完成内容

- `#editor` 使用 block 布局，根布局固定视口并禁止外层滚动；编辑器自身负责源码和结构化长文档滚动。
- 新增保留原文的 `protected_block`，预览 front matter、GFM 表格，以及含 Wiki link 的顶层段落、标题、列表、引用。
- 普通正文继续通过既有安全检测和 ProseMirror 编辑路径；扩展序列化使用节点原文，HTML 仅用于预览。
- CRLF 扩展路径沿用既有防止无关规范化的检查。
- 原文节点支持 DOM 复制往返；未修改快照、LF/CRLF、正文局部编辑、保存确认、Undo/Redo 均有回归覆盖。
- 未新增依赖；未修改用户 Obsidian 文件；未创建 PR 或合并 main。

## 边界与风险

- 扩展块目前为原子预览，仅支持整块选择、删除和历史恢复；不支持块内编辑或 Wiki 目标导航。
- front matter 显示原文，表格显示表格，Wiki 显示别名或目标；含 Wiki 的列表作为整个顶层列表保留。
- 普通正文仍使用既有 codec 规范化规则；块间空行尚无源范围保真保证。
- 严格安全检测没有放宽；不能覆盖的语法仍回退源码。混合换行和 bare CR 策略不变。
