## 公共接缝与实现

1. `SourceAuthoritySession` 把 asset ID 到当前真实图片 owner 的映射纳入历史快照。首次路径事务成功但 Markdown 写失败后，同目标重试经唯一图片 atom 校验成为严格 no-op；异目标从当前 owner 产生单一补丁。源码把 owner 改成普通链接、重复或删除时拒绝，不做全局字符串替换。
2. `RecoveryStore.discover()` 从正式 `LocalImages/<session>/manifest.json` 启动入口发现 pending 图片意图。验证通过后保留 document/session/epoch/revision/directed selection，改为 `requiresConfirmation` 并交给 `RecoveryCoordinator`；坏证据单独拒绝并保留原文件。独立子进程 SIGKILL 用例覆盖 manifest/字节落盘后、正文恢复草稿未落的窗口。
3. `LocalImageMigrationCoordinator` 的行内图片 owner 改为等长 mask 上的有界 scanner，覆盖平衡括号、angle destination/title、转义 delimiter；完整/折叠/快捷 reference 及 escape/entity/case/whitespace 归一化仍由既有契约处理。普通链接、代码、注释、转义和未闭合伪图不取得所有权；Save As Markdown 字节不变。
4. `DocumentAssetBroker` 的同步、异步读取统一在 broker 内取得 security-scope lease。同步预检在 descriptor 实读全程持有 lease，成功、checksum 失败与异步 stop/完成均单次释放；hostless 注入 seam 不外推为真实 OS 授权。

## 验收边界

- 自动层：真实 source-authority/runtime/history、RecoveryStore 启动 discovery、独立进程 SIGKILL、真实文件迁移与 descriptor-relative broker 读取。
