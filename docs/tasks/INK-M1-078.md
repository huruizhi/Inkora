# INK-M1-078：当前生产路径性能测量

固定产品起点 a58b8ba（图片组合候选，含core/V3/V6）；只修改性能接缝、入口与测量文档，无产品实现变化。已形成分层测量候选；测量可运行不等同于预算通过。

## 已核实差距

历史 `editor.perf.ts` 调用 InkoraEditorSession、doc.eq和整篇serializer；其有效基准保留，但不代表新原文权威生产路径。旧WK基准把CRLF当作强制源码模式，这一假设已过期。实际原版大文档快照测试 exit65，xcresult记录 InvalidTransition idle→failed(deinit)，不能未经验证归因成textarea API错误。

## 接缝与边界

- 公共SourceAuthoritySession：原文/投影可审计打开、选区+输入、保存资格快照、源码no-op、内存保存点；五次样本+一次预热，保留原始值、median/p95/CV及原文/源码hash。不是DOM、Bridge、磁盘或IME证据。
- 离屏真实WKWebView：生产DOM/模式按钮和Bridge，以完整原文快照确认打开、普通输入、源码no-op及快照。输入计时终点是精确快照回执，不能称可见绘制。没有物理中文composition。
- 既有small/medium/large/large-crlf样本及legacy bench保留；新增混排样本不替换旧样本。测量中的不支持/失败必须记录，不把失败样本删除或改小冒称通过。
- 此任务不启动App/XCUITest/窗口，不运行bench-full，不解除用户暂缓的物理/桌面验收。最低macOS14与正式用户文件写盘、可见paint/IME仍待验。

## 入口

`make bench-production-model` 为额外opt-in路径，不改变默认CI的make bench。默认全部五输入；`INKORA_PRODUCTION_PERF_SIZES=small,mixed` 只用于冒烟并在报告保留选择范围。原性能基线JSON不改绿、不把旧serializer数值与新currentRaw直接作相同指标比较。
