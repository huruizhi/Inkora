# INK-006：实现核心块级 Markdown 编辑行为

- 来源：GitHub Issue #6
- 分支：`task/INK-006-block-editing`
- 依赖：INK-008 / Issue #8、INK-007 / Issue #7

## 交付范围

- blockquote、code block、有序/无序列表和 list item schema；
- 标题与 paragraph 转换、列表/引用包装和提升、分隔线插入；
- Enter、Backspace、Tab、Shift+Tab 与 code block 退出键盘行为；
- 标题、引用、列表、代码块、分隔线输入规则及局部撤销；
- 嵌套合法性、命令、退出、粘贴与 DOM 解析测试。

## 依赖说明

`prosemirror-schema-list` 提供与 ProseMirror transform/command 协议一致的标准 list schema 基础和 split/lift/sink/wrap 命令；Inkora 在其上收紧有序列表正整数约束。

## 非范围

- 表格、任务列表和多栏布局；
- Markdown parser/serializer 与 golden fixtures（Issue #9）；
- 全局 Undo/Redo 与 dirty（Issue #11）。
