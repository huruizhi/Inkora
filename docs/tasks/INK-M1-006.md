# INK-M1-006 大纲定位与折叠空间

## 完成范围

- 大纲标题改为可键盘访问的真实按钮，按分析顺序定位重复标题。
- 导航请求绑定 `documentID/revision/raw` 和标题原文范围；过期、跨文档、composition 与不可证明映射均拒绝并显示局部提示。
- 结构化编辑器逐项验证原文标题与 ProseMirror heading 序列后，以不进入历史的选区事务定位并滚动。
- 源码/只读编辑器显式映射 BOM、CRLF、混合 EOL 与裸 CR 的 UTF-16 原文偏移。
- 收起状态在宽窗释放侧栏宽度，在窄窗释放面板高度，并保留展开按钮。

## 不变量

导航不修改原文、dirty、revision、Undo/Redo、保存点或 Bridge 消息；失败不改变正文焦点与选区。未增加 Bridge 协议、依赖或通用 raw offset 到 ProseMirror position 承诺。

## 验证边界

jsdom 测试覆盖真实 runtime、main 和 DOM 接缝，但不冒充 WKWebView 布局及真实 IME。实际 UI 点验由管理者独立完成。

## 限定补正（加载代际与映射内部边界）

首稿复核确认两处真实缺陷：同 docID/revision/raw 的合法重复 load 后，旧面板按钮仍可移动新视图光标；`rawOffsetToTextareaOffset("a\r\nb", 2)` 错误返回 2 而非 `undefined`。

- `main.ts` 新增 `loadEpoch`：每次**已接受**的 `loadDocument` 递增并写入面板快照；导航请求核对 `epoch`，旧代际请求拒绝且不改选区/焦点、不发消息。被拒 load 不递增，当前导航保持有效。
- `heading-navigation.ts` 显式拒绝 CRLF 对内部与拆开代理对的偏移；有效标题边界与原文不变。
- 临时复测文件 `editor/src/root-outline-review.test.ts`（复制自管理者冻结档案，只读源）修复前 2 红 1 绿、修复后 3/3 通过，随后已删除；产品内补对应回归（main 同身份重载旧按钮拒绝+新按钮可导航、被拒 load 不失效、CRLF/代理对内部偏移拒绝）。
- 实际命令结果：`pnpm exec vitest run`（完整非 UI，含 bridge）全过；`pnpm lint`（tsc --noEmit）0 错误；`pnpm build` 成功；`git diff --check` 干净。临时文件与 node_modules 符号链接已清理后重跑确认。

## 风险与未验收

- source/只读模式长文档下 `focus()`+`setSelectionRange(offset, offset)` 是否必然把目标滚动到可见，jsdom 无真实布局证据，也未在真实 WKWebView 点验：**滚动可见性未验收**。未自扩 GUI；如实际滚动不可靠，可在真实 UI 验证后补只读滚动接缝（不改 kernel/setText）。
- 结构化模式滚动走 ProseMirror `scrollIntoView()`，同样依赖真实视口，最终体验由管理者 UI 点验。
