## 交付范围

- `editor/src/document-analysis.ts`：`analyzeDocument({ raw, revision }, { excludedRanges? })` 纯函数；
  - 大纲：markdown-it（CommonMark）ATX 1–6 与 Setext，嵌套容器、重复标题、代码假标题、不闭合围栏；偏移为原文 UTF-16 半开区间，BOM/CRLF/LF/混合 EOL/无尾换行均按原文长度定位；
  - 统计：原文口径（含 Markdown 符号、不受排除影响）与内容口径（正常文本、行内 code、code block、图片 alt、链接 label；不含 url/title/引用定义/定界符）；
  - 计数规则：字素簇计字符（空白不计，BOM/emoji/ZWJ/组合重音各 1）；写作单元 = 每汉字素 1 + 其他字母数字连续串 1，标点/emoji/`_`/`-` 只分隔；
  - `excludedRanges`：非法/越界/重叠/切断 CRLF/切断字素明确拒绝（`ExcludedRangeError`）；在等长解析副本上屏蔽，不改原文；
- `editor/src/document-analysis.test.ts`：24 个用例，覆盖中文/英文/emoji ZWJ/组合重音、BOM/CRLF/混合 EOL/无尾换行、空文档、代码假标题、Setext 与分隔线、重复标题、链接/图片 alt/代码文本、排除范围与无修改保证、约 2000 行有界规模烟测；
- `docs/document-analysis.md`：口径与规则说明。

## 非范围

- 不修改 schema/parser/runtime/PM/Bridge/NSDocument 或任何冻结资料；
- 不新增 UI/插件/依赖；不执行 HTML；不是完整公式/元数据引擎，也不是 Typora 各语言计数的精确复刻；
- 规模烟测不冒充真实 WK 性能预算；M1 整体验收与生产集成另行进行。
