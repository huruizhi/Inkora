# INK-007：实现行内格式、链接与输入规则

- 来源：GitHub Issue #7
- 分支：`task/INK-007-inline-formatting`
- 依赖：INK-008 / Issue #8

## 交付范围

- strong、em、strike、code、link schema marks 与 DOM 规则；
- 空选区、普通选区和跨文本块选区命令；
- 可注入链接获取回调的 macOS 快捷键；
- composition-safe 输入规则及其局部撤销；
- 支持 mark 的富文本粘贴解析与未知容器降级；
- 输入、选择、链接、粘贴和输入规则撤销测试。

## 依赖说明

- `prosemirror-state`、`prosemirror-commands`、`prosemirror-inputrules`、`prosemirror-keymap` 与 `prosemirror-view` 提供官方状态、命令和插件协议；
- `jsdom` 及其类型仅用于在 Vitest 中实际执行 DOM 粘贴解析。

## 非范围

- Markdown parser/serializer 与 golden fixtures（Issue #9）；
- 全局 Undo/Redo、dirty 与完整 clipboard 策略（Issue #11）；
- 图片、脚注与插件格式。
