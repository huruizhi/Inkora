# INK-M1-002：当前原文的查找替换

## 范围

实现可复用的纯原文查找、导航和替换计划模块，不接入生产 UI 或编辑器运行时，不读写磁盘，不改变既有解析、schema、ProseMirror、Bridge 或 NSDocument。

## 已完成

- 字面、默认非重叠的原文搜索，支持大小写敏感与 ECMAScript Unicode 简单大小写匹配。
- 精确 UTF-16 半开范围，并显式筛除切断 surrogate、字素、CRLF 或覆盖开头 BOM 的匹配。
- 默认 10000 结果上限、可配置更小正整数及显式截断状态。
- 基于有向选区的前后查找、可选回绕、方向保持和避免重复当前匹配。
- 单个/全部替换的纯 patch 计划、字面替换文本、降序应用顺序及结果选区。
- 原文与 revision 双重过期校验；截断全部替换、非法 Unicode、非法边界和结果 caret 合并风险均原子失败并保留意图。
- 中文、代码/引用、重复与重叠、emoji/ZWJ/组合重音、BOM/混合 EOL、大小写反例、空查询、`$` 文本、no-op、过期、截断、导航和恶意边界测试。

## 非范围与后续责任

- 未实现 UI、可视模式保护区策略、编辑器适配器、自动 dirty/history/save 或文件写入。
- 未宣称 M0 真实 WKWebView/搜狗验证、M1 整体验收或架构采纳。
- 未来适配器必须把一个替换计划作为单一历史事务，并独立验证 composition、保护片段、安全保存及真实性能。
- 有界规模烟测只验证搜索上限，不替代 WK 性能预算。
