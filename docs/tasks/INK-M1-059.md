## 本任务补正

- 生产 `Mod-K` 进入离线、键盘可达的链接表单，可创建和编辑 `href` / `title`，也可移除链接；`Mod-Shift-K` 保留为直接移除入口。表单不使用 `window.prompt`，不扩 Bridge 协议。
- 链接异步提交同时绑定当前原文、会话 revision、有向原文/可视选区和 epoch。composition、正文或选区变化、Undo/Redo、重复或跨文档 load 后的旧表单均拒绝提交。
- 取消、Escape、相同属性提交和非法 destination 不修改原文、dirty、history 或选区；destination 继续使用局部 Markdown 补丁既有的控制字符、空白与尖括号限制。
- `Mod-Option-C` 把当前段落转换为围栏代码块；`Mod-Enter` 从当前围栏代码块退出。两条命令都只补丁目标块边界，在多块文档内保留 BOM、逐边界 EOL、相邻块、围栏和末尾换行状态。
- 代码转换按目标事务位置寻找局部块，不再要求整个文档只有一个顶层块；退出命令只接受经过结构形状校验的“代码块后插入空段”事务，并显式提供可证明的源码 caret。

## 验证边界

- jsdom 集成通过真实 `EditorView`、DOM `keydown`、生产 `main`、Bridge 会话和快照验证；不使用只调用 `setLink` 的测试替身冒充入口。
- 自动化覆盖链接创建/取消/no-op/编辑/移除/Undo/Redo、composition、非法 href、跨 load 旧表单，以及多块代码转换/退出、CRLF、BOM、无尾换行、选区和单步历史。
- 未运行 GUI、App、WKWebView、物理输入法、XCUITest 或 NSDocument；这些仍由管理者按任务授权稍后验收。
