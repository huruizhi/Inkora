# INK-002：冻结 Markdown 支持矩阵与数据保真规则

- 来源：GitHub Issue #2
- 分支：`task/INK-002-markdown-support-matrix`
- 依赖：Roadmap #1
- 性质：规范任务，不实现编辑器或解析器

## 目标

为 Inkora 1.0 冻结 Markdown 语法边界和数据安全契约，使后续 schema、解析器、编辑器与 golden fixtures 使用同一套可验证规则。

## 交付物

唯一规范来源为 [`docs/markdown-support.md`](../markdown-support.md)。本任务文件仅记录工作范围，不复制或改写规范内容。

规范必须覆盖：

- 支持、延后和不支持的语法；
- 未修改、局部修改和重新序列化时的保真级别；
- UTF-8、Unicode、换行符、尾部换行与空白边界；
- 未知或不可安全往返结构的保留、只读和阻止保存策略；
- 可直接转化为自动化用例的 golden fixture 清单。

## 非范围

- 选择或实现 Markdown 解析器；
- 实现 WYSIWYG、源码编辑或预览界面；
- 创建 fixture 文件和测试框架；
- 修改已有架构或发行决策。

## 验收条件

- [x] 单一规范包含稳定规则 ID，后续 schema 和 fixtures 可引用这些 ID。
- [x] 所有延后、不支持和未知结构都有明确的无损处理与保存策略。
- [x] 规则覆盖中文、Unicode、代码块、混合换行和空白边界。
- [x] golden fixture 清单定义输入、操作与预期不变量。
