# INK-017：原生菜单与快捷键

- 来源：GitHub Issue #17
- 分支：`task/INK-017-native-menus`
- 依赖：NSDocument 打开/保存、编辑器 history、Bridge command

## 交付范围

- File > Open、Save、Save As 与标准快捷键；
- Edit > Undo、Redo 与标准快捷键；
- WKWebView 焦点下的 responder chain 命令转发；
- 由编辑器 `canUndo` / `canRedo` 驱动的菜单启用状态；
- revision-aware Undo/Redo 串行命令队列、超时与失败反馈；
- XCTest 和 XCUITest 菜单/快捷键覆盖。

## 非范围

- Typora 的完整菜单集合；
- dirty 关闭确认（INK-018）；
- Open Recent（INK-019）。
