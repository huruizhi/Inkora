# INK-M1-085：复用同值解析与按需字素边界证明

固定基线 `cb54a96f3edeea86e16f1b42db669fd776f23146`。目标是继续降低真实生产输入成本，保留完整原文、位置依据和失败保护；不是更换 parser 或缩减大文件能力。

## 实施与分阶段验证

1. 公共模型基线先实跑：large/large-crlf 选区+单字输入+保存资格中位数为 1272.00/1273.50ms。相同输入、预热和采样次数不变；medium V8 worker profile 确认原文解析、账本、字素边界均有实际成本。
2. SourceAuthoritySession 内只保留一项按完整 raw 值绑定的纯解析结果，复用事务检查、接受与账本建立的重复解析。它不复用 PM 意图或通过资格；079 的 raw/PM doc identity/projection identity 上下文校验继续完整执行。
3. 解析复用单独串行模型复测 1MB 为1002.97/1046.70ms；离屏 WK 为1036.01/1032.80ms。一次与其他检查重叠的 CRLF 测量 cv=0.277，原始序列保留为 noisy，不用它冻结预算。
4. 第二个单变量：为当前完整原文保留 Intl.Segments，用 containing 查询请求位置是否为字素起点，替代给每个原文字符分配 Set 项。BOM、CRLF、代理对检查先执行；不截取局部窗口、不猜 ASCII，也不绕过账本。批量可视替换的既有完整 boundary Set 仍保留。
5. 新增两项公共选区序列回归，手工指定旗帜、组合重音、emoji ZWJ、Hangul 和 Indic 元音组合的合法边界，并逐个 UTF-16 位置验证；原文变更、Undo/Redo、source apply/no-op 后仍重证边界。没有用缓存计数断言内部实现。

## 最终实测

M6/macOS27.2，本机 Node 公共模型和真实 hostless WK。输入与源码/bundle SHA、原始样本在 [证据目录](../evidence/INK-M1-085/)。Node 1预热+5采样；WK 1预热+3工作流，每工作流5快照；p95只是小样本顺序统计值。

| 指标 | medium 中位数 | large LF 中位数 | large CRLF 中位数 |
| --- | ---: | ---: | ---: |
| 最终模型选区+输入+保存资格 | 92.75ms | 916.27ms | 886.19ms |
| 最终 WK 普通输入→精确快照回执 | 133.14ms | 970.91ms | 964.83ms |

CRLF WK p95 为1048.63ms，未全部低于1秒；本机中位数达到方向性目标，不因此冻结正式全分位数预算或承诺最低系统/可见绘制/输入法响应。

## 范围、风险与后续

修改 SourceAuthoritySession、公共边界序列测试、性能记录和本任务/证据；无依赖、协议字段或 Swift 生产改动。单项解析缓存仅持有最近一次 raw 的结果，PM doc 按 ProseMirror 不可变契约使用；任何新 raw 重新解析，任何新投影仍重新证明。
