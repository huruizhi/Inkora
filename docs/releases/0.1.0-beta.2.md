# Inkora 0.1.0 Beta 2：未签名预览版

用户已授权本轮未签名预览发布；本地候选由管理者核验后实际发布。macOS Gatekeeper 可能拦截，本版仅供预览。无 Developer ID 分发签名、Apple 公证或 Gatekeeper 下载首启验收；dry-run 导出 App 仅保留 ad-hoc/runtime 结构签名。旧 Beta1 标签与资产保持不变。

## 版本与实际差异

App 版本为 0.1.0 / build 5，部署目标 macOS 14+。候选实测包含 arm64、x86_64，支持 Apple Silicon 与 Intel。渠道为 GitHub 直接分发，不上架 App Store。

对比固定 Beta1 标签 `v0.1.0-beta.1`（e123772、build3；原始产品源码 bd45d4bd4bb62e9cc5ae4d8891664de5b6183cc4），本轮已合并的变化为：

- 原生只读“检查更新”：读取公开发布信息，区分稳定与 Beta 渠道，主动打开发布页；不自动下载或安装，也不启用生产 Sparkle feed 或公钥。Beta1 没有更新客户端，需要手动下载安装本版。
- 默认阅读列从 760px 调整为 900px，仍可切换；收紧相邻标题的阅读间距。
- 查找与替换分开，通过 Cmd+F / 原生菜单进入按需面板；标题行右上按需显示统计与侧栏开关，统计可选阅读时间、行数、字数、字符数四种口径；侧栏支持文件、目录和搜索导航，并验证授权根与文件位置，取消过期导航。
- 原生写作命令及可用状态同步；应用图标采用更轻的光标笔画。
- 表格工具收拢为上下文菜单，并按可见编辑区域约束位置。
- 技术块源码修改入口绑定目标，脚注往返返回精确来源；修复 Mermaid 编辑入口的条件显隐。
- 图片描述表单保留刷新期间的草稿，防止过期操作和会话收尾期间误写；渲染器许可在离线只读对话框显示。

Markdown 原文权威、模式往返、撤销重做、BOM/EOL/Unicode、本地图片保存恢复、离线块公式/Mermaid/脚注均为既有能力，并非本版首次新增。目标或位置失效会关闭未应用的图片属性输入，跨节点草稿恢复尚未实现；该继承风险有人工调度 NodeView probe 证据，不代表物理路径验收。行内标记显隐原型不在本候选新增范围。

## 验证边界与已知限制

本地打包、版本、架构、签名结构与资源检查见 INK-REL-161 清单；PROVENANCE.json 绑定两包摘要及真实构建源码。发布前对精确提交结算默认非 UI CI，实际链接和结果见 GitHub 发行说明与 SOURCE.txt；此前功能 CI 不替代本版 CI。

不宣称 Typora 像素或功能完全一致。行内数学仍未支持；技术预览继续受离线与预算限制。尚未验证真实 paint、人工 VoiceOver、真实系统授权、干净用户及 quarantine/Gatekeeper 首启。用户取消的 macOS14 专项与重复物理 IME 不复做，部署目标不变。

本轮候选准备不启动 App、不安装；管理者负责 tag/Release/上传及公开复验。本轮未签名发布例外已获用户明确授权，旧 build4 候选不覆盖。正式发行仍须持凭据执行严格 `make release` 并完成人工验收。建议后续预览仅使用已备份的测试 Markdown。
