# Inkora 0.1.0 Beta 2：本地候选，未发布

本候选仅供本地审阅，没有公开发布授权。无 Developer ID 分发签名、Apple 公证或 Gatekeeper 下载首启验收；dry-run 导出 App 仅保留 ad-hoc/runtime 结构签名。旧 Beta1 标签与资产保持不变。

## 版本与实际差异

App 版本为 0.1.0 / build 4，部署目标 macOS 14+。CPU 架构以候选实测清单为准，不由 generic destination 推断。渠道仍为 GitHub 直接分发规划，不上架 App Store。

对比固定 Beta1 标签 `v0.1.0-beta.1`（e123772、build3；原始产品源码 bd45d4bd4bb62e9cc5ae4d8891664de5b6183cc4），本轮已合并的变化为：

- 默认阅读列从 760px 调整为 900px，仍可切换；收紧相邻标题的阅读间距。
- 右上查找/替换与大纲入口、安静标题控件、底栏统计，以及按需侧栏；侧栏支持文件、目录和搜索导航，并验证授权根与文件位置，取消过期导航。
- 原生写作命令及可用状态同步；应用图标采用更轻的光标笔画。
- 表格工具收拢为上下文菜单，并按可见编辑区域约束位置。
- 技术块源码修改入口绑定目标，脚注往返返回精确来源；修复 Mermaid 编辑入口的条件显隐。
- 图片描述表单保留刷新期间的草稿，防止过期操作和会话收尾期间误写；渲染器许可在离线只读对话框显示。

Markdown 原文权威、模式往返、撤销重做、BOM/EOL/Unicode、本地图片保存恢复、离线块公式/Mermaid/脚注均为既有能力，并非本版首次新增。图片跨节点属性草稿政策与行内标记显隐原型不在本候选新增范围。

## 验证边界与已知限制

本地打包、版本、架构、签名结构与资源检查见 INK-REL-147 清单及 PROVENANCE.json；候选精确提交的默认 CI 为 pending，由管理者集中结算。此前功能 CI 不替代该提交的 CI。

不宣称 Typora 像素或功能完全一致。行内数学仍未支持；技术预览继续受离线与预算限制。尚未验证真实 paint、人工 VoiceOver、真实系统授权、干净用户及 quarantine/Gatekeeper 首启。用户取消的 macOS14 专项与重复物理 IME 不复做，部署目标不变。

本轮不启动 App、不安装、不建 tag/Release/draft、不上传资产，也不沿用仅针对 Beta1 的未签名公开发布例外。正式发行仍须持凭据执行严格 `make release` 并完成人工验收。建议后续预览仅使用已备份的测试 Markdown。
