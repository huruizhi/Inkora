# Inkora 0.1.0 Beta 1：未签名预览版

**本版未做 Developer ID 签名或 Apple 公证。macOS Gatekeeper 可能拦截打开；仅供预览，不保证默认安全设置下首次启动成功。**
二进制保留构建时的 ad-hoc 签名；这里的“未签名”指没有可验证开发者身份的 Developer ID 分发签名。
发行渠道为 GitHub Releases 直接下载，不上架 Mac App Store。
用户已授权将现有仓库改为 public，发行页面与安装包可匿名访问；沿用同一版本标签及已校验附件，不另建下载仓库。

## 本轮变化

- 统一正文、标题、列表、引用、代码和表格排版，按编辑区域计算阅读行宽。
- 大纲左侧按需展开，统计移至底栏，表格/代码工具随光标与选中状态显示。
- Option+F10 进入上下文工具，Esc 返回正文。
- 块公式离线 MathML、Mermaid 本地图形预览及源码编辑入口、脚注上标和格式化说明。
- 保留 Markdown 原文权威、选区、Undo/Redo、BOM/EOL/Unicode、表格任务、查找替换及本地图片流程。

## 验证与限制

本轮产品验证：Web 777 项；Native 182 passed / 0 failed / 8 项既有性能 skip；Bridge Web 14 / Swift 15；lint、非 UI 门禁及 Release archive/ZIP/DMG 结构与离线资源检查通过。
关联 [PR #80](https://github.com/huruizhi/Inkora/pull/80) 与 [成功 CI](https://github.com/huruizhi/Inkora/actions/runs/42740102696)。

- 行内 `$...$` 仍未支持；块公式和脚注通过主动源码修改。
- Mermaid 外部资源、文档内配置或超过预算的图表保留代码和诊断。
- 最终桌面视觉、深色外观和完整窗口交互未完成最终复查；自动验证不代表物理 IME、正式下载首启或完整 Typora 对齐验收。
- 建议使用测试文档并备份原始 Markdown。包内离线资源不要求 CDN 或外部字体。

下载后用随附清单校验：

```sh
shasum -a 256 -c SHA256SUMS
```

打开候选前先退出正在运行的旧 Inkora，避免同一 bundle id 把文件交给旧实例；可在关于窗口核对版本与 build。
本发布流程不会关闭 Gatekeeper 或移除 quarantine。系统若拒绝运行，可保留错误提示，或依照仓库开发说明从源码构建。
