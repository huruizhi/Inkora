# 当前原文为唯一内容权威，ProseMirror 承载可编辑投影

采用唯一当前 Markdown 原文、派生语义解析和带位置依据的 ProseMirror 可编辑投影。保留现有 PM/离线工具链；已接受编辑原子更新原文、投影、位置与历史，保存只在成功收据后更新保存点。不能以语义 AST 相等作为所有合法编辑的普遍提交闸门，也不能让合法空格或空行无限期停在禁止保存/源码查看的缓冲状态。

027 的增量模型已出现同字节因打开/输入路径不同而获得不同保存资格。028两轮独立评审收敛为同一边界：目标契约为 source-authoritative，隔离原型是验证容器，settle只能是接受事务时的内部迁移机制。029冻结判据后，030/031/034及036限定补正提供了字节、位置、历史、真实WK和物理搜狗证据，见[证据裁定](../decisions/M0-source-authority-verdict.md)。管理者依据用户“后续按照建议选择、继续推进”的授权作此采纳；不是声称用户逐行签认了实现。

不采用继续给staged的Save/Source入口叠加特例；也不需要先替换PM框架。无条件重解析放行、盲找首次同文、无审计trim，以及把真实softbreak隐藏成无换行投影均不符合此决定。无法证明的编辑须保留原文和完整意图、明确阻断不安全保存并开放主动源码修复。

后果：生产须重新实现文档会话与原文位置边界，保留现有Bridge/NSDocument保存保护及已合写作辅助。原型只证明有界可行性，禁止整目录搬运、导入prototype或直接把原型版本号当Bridge revision。正式迁移执行[V1规格](../design/source-authority-production-v1.md)，并逐阶段完成表格/任务/图片/高亮/可视查找替换。M0通过不代表这些功能、最低系统、性能或发布已通过。
