# Typora 表格首批实施规格

本轮范围由用户选择：`TP-TBL-02`～`TP-TBL-06`，其余官网需求不并入本批。来源为用户指定 `.worktrees/INK-AUDIT-179/docs/design/typora-homepage-gap-audit.md` 的“建议第一批实施范围”，其产品核对基线是755dc6c。开发基线更新为输入修复合并后的 main@16d0a62。

## 作者操作与边界

- **TP-TBL-02 参数建表**：Native“插入表格”或Web同名按钮打开离线对话框。列数1～20，总行数1～100，含且仅含第一表头行；默认2×2。确认后进入第一表头格开头。非法参数、取消或过期意图不改变内容。3列4行是代表场景。
- **TP-TBL-03 规模选择**：表格工具“规模”打开二维10×10网格，指针经过时高亮矩形范围并更新“列×总行数”。方向键移动预览；Enter/Space选择。数字输入支持完整20列100行上限。扩展确认一次应用；所有缩减必须勾选明确删除确认。勾选前不提交，改变预览后重新确认。
- **TP-TBL-04/05 重排**：列上方、数据行左侧的手柄可以拖动。列连同表头、对齐分隔单元及全部数据格移动；数据行整行移动，表头不能移动。键盘聚焦手柄后使用←→或↑↓执行相同命令。代表顺序为A/C/B→A/B/C和1/2/3→2/1/3。
- **TP-TBL-06 反馈**：拖动时显示原行列范围及插入线，放下后的顺序与最后显示指示一致；内容只在放下提交一次。Esc、pointercancel、失焦、composition或过期状态取消，no-op不产生历史。横向拖动靠近表格滚动边缘时滚动表格。

这里“行”在规模中含表头；数据行的内部命令索引从1开始。列索引从0开始。规模不会产生零列表格；删除整表沿用原命令。

## 原文、历史与取消

沿用当前原文为唯一权威，UI显示不作为正文。新结构经`inkoraTableCommand`进入既有事务路径；局部候选完整重解析后须与目标投影一致，未证明则原子拒绝。不是放宽普通输入或保存资格。

保留范围外原文、BOM、容器前缀、各物理位置EOL、转义管道、单元格原始格式和对齐。移动数据行时整行载荷移动，换行符留在物理目的位置。缺格在必须移动/扩展时补足空格；可选首尾管道不统一重排。超出表头宽度的原文尾格继续保留；扩列在这些尾格前插入新空格，避免意外提升隐藏数据。缩列删除被移除的可见列；已存在隐藏尾格保持隐藏。缩行删除该行完整原文，包含隐藏格，因此所有缩减均明确确认。存活末行沿用其原有换行；原文件在表格末尾EOF没有换行时继续保留无末尾换行。

每次内容确认/拖放是单个撤销单位；Undo恢复完整原始字节，Redo恢复结果。预览、取消、非法参数和边界no-op不涨正文revision，不增加历史。组合输入及settling阶段由runtime/NodeView现有守卫阻断。未应用的表格规模不是源码草稿，不进入保存内容。

## 模块与实施顺序

1. `table-commands.ts`集中纯命令类型和规模策略；`table-editing.ts`：尺寸验证、参数构造及统一重排/resize命令与PM目标；runtime提供参数插表，保留默认即时调用兼容已有调用者。
2. `source-transaction.ts`：从当前表格范围获取物理行和原始格，生成目标原文；不通过序列化整文档实现排序。
3. `table-size-dialog.ts/css`：本地绑定意图、参数与网格、缩减确认、焦点/键盘/取消；对话框放在编辑器外，数字字段的组合输入只属于本地UI，不被正文composition捕获；Native协议仍使用现有`insertTable`命令。
4. `table-interactions.ts/css`：独立于contentDOM的手柄/预览/指示线，拖动最终调用统一命令。当前EditorState及节点生命周期是资格依据。
5. `main.ts`：原生/Web入口改为请求对话框；异步确认经既有文档发布路径涨revision一次。

## 验证与完成口径

沿用审计指定公共runtime/EditorView/正式命令接缝，不新增测试专用产品入口。运行时验证字节、投影、历史和过期/组合输入；main/Bridge验证无修改预览和单次发布。Native/WK专项使用实际离线bundle与InkoraDocument，窗口始终不可见；900/360px检查滚动和网格/手柄命中，真实保存到自有临时样稿后重开。

隐藏WK合成事件不等于物理鼠标或IME，命中几何不等于屏幕paint；VoiceOver与macOS14实机仍须人工验收。本批不包含Markdown表头回车建表（TP-TBL-01）、新语法、联网、主题和其他54项。最终命令/证据见[任务记录](../tasks/INK-UX-182.md)。
