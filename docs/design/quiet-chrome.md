# 安静顶栏与阅读宽度对照

INK-UX-123，基线`27ba9e07e7229fe13a2374c8c15be3f0c166e1c1`。用户已确认先补原生菜单/快捷键再收顶栏，以及760/约900px对照后决定默认宽度；本片只实施这两项，不扩展公式/脚注/行内标记或表格工具重排。

## 行为契约

1. Native“显示”菜单提供可视/源码模式、源码提交/取消、大纲及760/900px阅读宽度；“插入”提供表格与图片，“Edit”补查找。命令target为空，经当前文档响应者链路由，不绑定全局第一个窗口。
2. 快捷键：查找⌘F、可视⌘⌥1、源码⌘⌥2、表格⌘⌥T、图片⌘⇧I、大纲⌘⇧O、提交源码⌘⌥Return。取消草稿无全局Esc快捷键，避免消费候选取消；源码区保留可见提交/取消按钮。
3. 菜单展开时请求当前资格；扩展动作执行前重新queryState并确认同一加载代际。Web对document/revision/requestID、composition、模式、草稿、文本控件焦点再次守卫。当前文档未ready或有sheet时不打开第二个文件面板。菜单缓存资格不代替执行校验。
4. 纯模式/阅读宽度/导航动作不改变原文、revision、dirty、保存点、history/future。有效源码提交/插表保持一次内容发布和合理Undo。过期动作不自动改绑新版本；reload取消旧排队/在途命令。
5. dirty源码草稿只能显式提交或取消，可视切换明确拒绝。查询/链接输入composition不可因命令被清空或切走；查找输入普通持焦时仍可显式切模式，但文档Undo/Redo/插表/插图不能越过其焦点修改正文。
6. 补齐入口后，Native宿主隐藏常驻可视/源码/插表按钮，移除原生叠加插图按钮及116px预留。保留轻量大纲/查找，正常阅读顶栏不再占独立整行；源码草稿与修复状态按需呈现。独立Web开发环境无Native菜单时保留原按钮，避免失去操作。
7. “显示→阅读宽度”提供760/900px两档，作用于当前文档工作区；不持久化为全局偏好。新窗口默认仍760px。窄窗按剩余空间收缩，源码保持等宽字体。用户尚未选择900px默认，不能据此宣称其更优或已经完成阅读验收。
