# V1：生产原文权威与基本写作纵向闭环

状态：可实施。基线main `48258a93b3fc4a75df21a22ac0d175e01943b744`，架构依据ADR-0004。V1是完整首阶段的第一纵向切片，不是首阶段范围缩减。

## 必须交付的行为

真实生产编辑器打开/新建中文技术文档，连续编辑正文、标题、列表、引用、格式、代码与链接，主动进入源码、提交或取消草稿，跨模式Undo/Redo，createSnapshot/正式保存收据、关闭重开。BOM、LF/CRLF/mixed EOL、无尾换行、Unicode和未编辑格式字节保留。稳定高级片段与正文混排，不因片段存在自动整篇源码；畸形输入保留完整原文和可信投影、明确问题与安全源码修复入口。

必须接入editor/src与现有main/runtime/Bridge真实路径；禁止只新增无人使用的纯模块后宣告V1完成，禁止import prototypes、暴露window调试控制器或整目录照搬。可按被证明职责逐文件迁移逻辑，遵循生产代码风格与锁定依赖。表格/任务勾选/图片完整直接交互由后续V3/V4负责，本切片可保留精确原文占位，但首阶段验收前必须替换为完整能力。

## 统一内容与会话契约

- 唯一当前原文保存所有已接受编辑；语义解析和PM文档均为派生状态。编辑补丁、投影、原文/可视有向选区、位置依据和历史原子更新。失败不半提交，保留完整候选与诊断。
- 保存点是成功写入的精确文本；dirty比较当前原文与保存点。源码草稿单独保留/标识并阻断不安全快照，不能冒充已提交原文。格式变化即使AST相同也须dirty。
- 当前模型内部版本可以随接受原文变化推进；Bridge revision继续遵守生产save-barrier：一次普通编辑/Undo/Redo或已结束IME逻辑单元一次发布；组合中间态不发多次文档revision。两种版本不得直接混用。
- 每个composition的原文/投影中间状态受守卫，最终确认/取消按一历史单元收口。end前后最终PM事务、连续会话、选区替换、取消/no-op保future均覆盖。不得用拼音字符串过滤或组合期额外刷新来假装正确。
- Save/source no-op/导航不规范化投影、不移动caret、不制造历史。主动源码入口读最新原文；草稿未提交时文档Undo/Redo拒绝并保留完整草稿，提供明确提交/取消。
- EOF原文位置与隐藏空白使用显式affinity和可审计依据；继承marks必须与原文语法相符。不能复制036初稿隐藏真实softbreak的做法。含混、非法Unicode/CRLF内部边界及未知结构事务仍保守拒绝并保留意图，普通已声明写作操作不得最终以“安全拒绝”代替实现。

## 生产集成接缝

1. 替换StructuredEditorRuntime的“AST dirty→整篇serialize”内容权威路径；现有getText返回唯一当前原文。旧SourceRuntime已有字节/history能力需迁入同一会话而非继续维护两个文档真值。
2. 提供可见且键盘可达的可视/源码入口及草稿提交/取消。模式切换属Web会话，不要求为此增加NativeCommand；若确需扩Bridge协议，先列双端改动与兼容测试，不能一侧私加字段。
3. createSnapshot只在同一turn从安全的当前会话取得text/revision；composition沿既有稳定边界排空，草稿/含混/未解决意图时拒绝本次保存并保留内容，不能返回最近可信旧文本充数。使用既有错误契约，修复后下次保存可恢复，不能留下永久stop_saving。
4. markSaved只接纳原生成功提交的snapshot文本为保存点；若期间已有新编辑则仍dirty，不把旧收据覆盖当前原文/选区/history。保留documentID/revision/requestID去重、拒绝load、快速连续Save和原生串行写入保护。
5. 大纲/统计/标题定位、查找框composition/焦点隔离及源码查找导航/单步替换保持可用。新映射未交付完整可视搜索前不渲染虚假定位/替换；后续V6必须完成可视写作查找替换。源码替换计划继续严格绑定raw/revision/epoch并作为一个历史事务，不旁路会话。
6. 不扩网络、entitlement或依赖。最低macOS14与正式NSDocument规则不变；bare CR只读保护可保留，BOM/CRLF/mixed EOL在支持范围应共享原文契约。

## 直接验收与退出条件

- 从真实createEditorRuntime/main DOM/Bridge seam建立先红后绿的集成回归，不用重复实现的测试替身。覆盖从load到原文快照、markSaved、再编辑、Undo/Redo和源码往返。
- 使用独立冻结输入/预期校验局部替换、marks/attrs、CRLF任务单字符、Enter/join、引用定义/同字碰撞、代码定界符和语言改动。原型窗口/按钮不是生产测试证据。
- 最小a+LF→Space停住→保存→source no-op→新会话重开→隐藏空格后续写/Backspace，及EOF续写必须保证raw、实际PM语义、caret、dirty和历史全部一致；包含strong/link等边界，不只正文字母。
- 组合确认/取消、两会话、选区替换、源码IME、compositionend晚事务、跨load及保存收据竞态测试；jsdom必须标synthetic，不冒充真实WK/搜狗。
- 原main315非UI基线与独立控制保持；因目标模式从整篇回退变为可视混排而需要改变旧mode断言时，保留原始字节/状态安全断言并列明理由，不删除有效测试或改oracle。make lint、editor build、完整editor tests实际执行。
- 原生保存/关闭/reopen/恢复与混排/源码模式实际联动，在管理者真实WK和NSDocument验收通过后才算V1交付；实现者非UI完成回报仅为候选。最低OS/性能/AX按发布清单分层，不虚报。
- 记录长文和对抗分隔符实际测量；不得宣称当前ledger最坏复杂度已线性化。性能硬门槛由预算票单独冻结，但异常/阻断不得丢文。
