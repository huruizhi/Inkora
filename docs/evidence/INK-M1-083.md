## 红绿反馈

- Native 原始红例：`LocalImageMigrationCoordinator.imageURIs` 把四空格缩进代码和 `$$` 保护块中的伪图片当 owner；生产 `SourceAuthoritySession` 对相同输入的 accepted PM 投影为 `images=[]` 且可保存。定向 XCTest 修复前 exit 65，证明 Native scanner 是冲突的第二语法真值。
- canonical proof 红例覆盖实际 production runtime：缩进代码/数学/quoted tilde fence 无 owner，list continuation 有 owner；并覆盖 reference first-wins、escape/entity、平衡括号、共享 reference 与同 URI 多 owner。修复后 proof 直接遍历 accepted PM 文档，不再从 Native raw 推断。
- 版本竞态红例：目录授权期间 revision 前进时，旧 owner plan 曾可能在新 revision 入队 rewrite。`EditorBridge` 现把 descriptor 与 `prepareImageSave` 固定到 proof document/revision；旧 proof 返回 `staleRevision`，不发送资源命令。
- 资源过滤红例：已删除但仍 accepted 的恢复 asset 现得到空首存 plan，manifest 与 PNG 字节保留；已证明无图的 Save As 通过注入 authorizer 计数为 0，缺 proof 明确失败且同样不请求授权。
- 080 handoff、首存 rewrite 后 snapshot 与 Save As migration 均要求严格 proof；失败不会确认 plan、清理恢复资产或调用 Markdown writer。
