## 五项红绿

1. 首存失败/Undo/重试：`LocalImageStoreTests.testFailedFirstSaveKeepsDraftOwnerForUndoAndSameTargetRetry` 在原实现 rc=65，表现为 publish 后 manifest owner 已改目标、同目标 retry rewrite 为 0；分离 publish/confirm 后 rc=0。同用例覆盖异目标、原 SHA/源字节、旧 receipt。`InkoraDocumentTests.testFirstSaveRejectsSnapshotThatStillOwnsDraftImageURI` 原实现 rc=65（writer 被调用），加入真实图片 owner 屏障后 rc=0。
2. 引用标签：`LocalImageMigrationTests.testSaveAsNormalizesCommonMarkReferenceLabelsWithoutChangingMarkdown` 原实现 rc=65、`planned=0`；canonical label 修复后 rc=0，并验证中文、空格、百分号路径和 Markdown 同字节。另有 escape、HTML named/numeric entity、普通链接、未使用定义负例。最终审阅新增跨行与转义括号 label 红例，原扫描器 rc=65；支持 CommonMark 单个换行与转义标点并执行 999 字符上限后，两个定向用例 rc=0。
3. pending 意图：原 manifest 无 epoch/revision/selection，恢复分支使用 `text.contains`。schema 2 意图测试验证 document/session/epoch/revision/directed selection 跨重启保留；draft URI 代码/普通正文负例只识别真实图片 owner。Bridge Web/Native golden 验证 selection 双端字段，运行时执行前再次比对 selection。
4. journal：原实现只有写入，没有枚举入口。`testRestartDiscoverySeparatesPublishedHistoryFromCurrentMarkdownIntegrity` 验证新 coordinator 的历史状态与当前 SHA 分离；`testRestartDiscoveryRejectsUnknownSchemaAndSymlinkWithoutDeletingEvidence` 验证拒绝且不删除；`testSIGKILLAfterPublicationIsDiscoveredByIndependentProcessState` 用真实子进程在 published-awaiting-markdown 后 `SIGKILL`，新进程读回资源与 journal。
5. 授权：删除 `documentURL.parent` 回退；恢复 bookmark 错误保持 unauthorized。descriptor 只有显式 grant 且 broker 实读为 ready 才下发 `ready`，无 grant 下发 `denied`。测试为注入/hostless 失败路径，不声称系统 Sandbox 授权已验。
