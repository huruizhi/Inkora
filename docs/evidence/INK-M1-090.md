# INK-M1-090 非 UI 证据

## 红绿反馈

- Web exact proof 红例：same-revision 命令分别只改变 raw、只改变 owner 数组时，旧实现均回 `stateChanged` 并应用 descriptor；composition 活跃时同样 ack。修复后前两者为 `stale_revision`、composition 为 `editor_not_ready`，DOM、revision、dirty/history 不变。
- Native stale-before-register 红例：r3 proof 面对当前 r4 时，descriptor provider 原先已在 Bridge 拒绝前注册；新公共 builder seam 在 provider 前拒绝，broker live/provisional 均保持 0。
- ack 竞争红例：r4 descriptor 已 provisional，Native 先观察 r5、再收到迟到 r4 ack；旧实现会完成成功并把 token 提升为 live。修复后 completion 为 `staleRevision`，token 进入 stale，live/provisional 均为 0。
- recovery 红例：当前 bridge revision 为 6、snapshot/proof 为自洽 r5 时，旧 `writeRecovery` 静默 return 后仍 accepted。修复后 receipt 缺失即失败；silent writer、throwing writer 同样保持 pending，fresh intent 保留，旧 draft/manifest/PNG 字节不变。
