已知边界 / 未验证
保护片段只读；任务仅复用列表中文字，不是完整 checkbox 节点。只有唯一可定位的文本叶节点可直接编辑；转义、重复文本、空段、跨块、一般结构键盘操作、移除 marks 与通用 link attrs 暂不支持并阻断。专用按钮验证 marks/标题 attrs、split/join。重解析等价检查不构成通用 Markdown 语法保真证明。
边界含混（无闭合围栏、行内 $ 等）时：缓冲保留用户输入并进入 pending，可视投影保守原样呈现问题片段（红框标注），结构化保存阻断；主动源码修复或 Undo 恢复一致性。行内 $ 定界、非精确围栏等输入按含混保守处理。
选区已接线（INK-PROT-010）：进入源码模式把可视 anchor/head 映射为 textarea LF 选区（保留方向）；提交时用 textarea 当前选区经生产 TextAreaEditorKernel 规范原文映射回新文档；Undo/Redo 恢复内容锚点与方向；吸附均注明且属近似而非精确映射。映射失败绝不静默重置：草稿/可信视图/原选区保持并给出原因，可移到安全锚点重试或取消；源码草稿未提交时 Undo/Redo 拒绝执行且不丢弃草稿（先提交或显式取消）。无内容块缓冲提交时回退选区先校验后提交：空文档/仅空白/仅引用定义 → 唯一空段落插入点（TextSelection@1，正常写作路径）；纯保护块 → 含源码光标的块整块锚点（NodeSelection，可见回退，记录为文本选区映射不支持、不判通过）；主动源码修复入口始终可达。重复文本/转义映射仍不完整，不宣称完整 source map。
历史采用原型共享快照，每个事务独立；没有生产 PM history 分组。未验证真实 WKWebView、系统中文 IME、composition 历史分组、App Sandbox、原生保存/重开/冲突，不可据此宣告 M0 门槛通过。无网络、无持久化、无生产代码修改。
